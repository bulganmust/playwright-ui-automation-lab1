# Playwright UI автомат тестийн лабораторийн ажил 1

## Төслийн тухай

Төслийг F.CSA313 - Программ хангамжийн чанарын баталгаа ба тест хичээлийн хүрээнд хийж гүйцэтгэсэн.

Төслийн зорилго нь Playwright ашиглан веб системийн хэрэглэгчийн интерфейсийг автомат тестээр шалгаж сурах.

Тестүүдийг SauceDemo веб сайтад хийж, хэрэглэгчийн нэвтрэх үйлдэл болон бараа сагсанд нэмэх үйлдлийг шалгасан.

## Хийгдсэн тестүүд

Төсөлд нийт 3 UI автомат тест хийсэн.

1. Зөв хэрэглэгчийн нэр, нууц үгээр амжилттай нэвтрэх
2. Буруу нууц үгээр нэвтрэх үед алдаа гарч байгаа эсэхийг шалгах
3. Амжилттай нэвтэрсний дараа бараа бүтээгдэхүүнийг сагсанд нэмэх

## Тестийн үр дүн

Нийт 3 тестийг ажиллуулж, бүгд амжилттай ажилласан.

Тестийн үр дүнг шалгахын тулд Playwright-ийн HTML Report ашигласан.

Мөн Trace Viewer ашиглан тестийн явцад хийгдсэн үйлдэл бүрийг дэлгэрэнгүй шалгасан.

## Playwright болон Selenium-ийн харьцуулалт

Playwright болон Selenium нь веб системийг автомат тест хийхэд ашиглагддаг хэрэгслүүд юм.

Playwright нь орчин үеийн веб тест хийхэд зориулагдсан бөгөөд Chromium, Firefox, WebKit зэрэг үндсэн browser-уудыг дэмждэг.

Мөн Playwright нь элементүүдийг автоматаар хүлээдэг тул тест бичихэд илүү хялбар байдаг.

Playwright-д HTML Report болон Trace Viewer зэрэг тестийн үр дүн болон алдааг шалгахад хэрэгтэй хэрэгслүүд багтсан байдаг.

Selenium нь олон жилийн турш ашиглагдаж байгаа бөгөөд олон төрлийн программчлалын хэл болон browser-ийг дэмждэг.

Selenium нь одоо ч гэсэн олон программ хангамжийн тестийн төсөлд өргөн ашиглагддаг.

Харин Playwright нь орчин үеийн locator, automatic waiting болон debugging хэрэгслүүдийг нэг дор агуулдаг учраас UI автомат тест хийхэд илүү тохиромжтой санагдсан.

Мөн Playwright дээр locator сонгохдоо XPath-аас аль болох зайлсхийхийг зөвлөдөг, учир нь XPath нь
HTML-ийн бүтцээс (элементийн байрлал, hierarchy) хэт хамааралтай тул frontend-ийн жижиг
өөрчлөлт хийхэд ч тест амархан эвдэрдэг. Харин getByRole, getByLabel, getByTestId зэрэг нь
хэрэглэгчийн харж/ашиглаж буй байдал дээр суурилдаг тул илүү тогтвортой, унших цөөн зохиогддог.
